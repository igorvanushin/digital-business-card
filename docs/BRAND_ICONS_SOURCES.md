# Источники брендовых логотипов (Telegram, VK, MAX)

Зафиксировано при внесении точечных визуальных исправлений в `site/`.
Файлы лежат в `site/assets/icons/`.

Обновление (актуальная версия): Telegram и VK заменены на официальные
**цветные** значки (было — монохромные/чёрные), по образцу уже
использовавшегося цветного MAX. Ни один логотип не нарисован вручную —
все три файла являются неизменёнными копиями, полученными напрямую
с официальных источников брендов, без hotlink — файлы скачаны и хранятся
локально.

## Telegram

- **Локальный файл:** `site/assets/icons/telegram.svg`
- **Источник:** официальный сайт `https://telegram.org/tour/screenshots`,
  прямая ссылка "Download Telegram Logos" →
  `https://telegram.org/file/464001088/1/bI7AJLo7oX4.287931.zip/374fe3b0a59dc60005`
  (файл `Logo.svg` из официального архива).
- **Вид:** голубой градиентный круг (`#2AABEE` → `#229ED9`) с белым знаком
  «бумажный самолётик» — актуальный официальный app-icon Telegram.
- **Сторонние источники (logo-teka.com и подобные) не использовались.**
- **Статус:** `CONFIRMED`

## VK

- **Локальный файл:** `site/assets/icons/vk.svg`
- **Источник:** официальный брендбук `https://vk.ru/brand` (встроенный
  виджет брендбука на `brand.production.vklanding.ru`) — иконка взята
  непосредственно из DOM официальной страницы брендбука, раздел
  «фирменные цвета» подтверждает HEX `#0077FF`.
- **Вид:** скруглённый квадрат фирменного синего цвета `#0077FF` с белой
  монограммой «VK», официальные пропорции и скругление сохранены без
  изменений.
- **Статус:** `CONFIRMED`

## MAX

- **Локальный файл:** `site/assets/icons/max.svg` (без изменений с
  предыдущей правки).
- **Источник:** официальный брендбук MAX — `https://go.max.ru/brandbook`
  (ссылка размещена на официальном сайте `https://max.ru`).
  Файл `Max colored.svg` из архива
  `https://st.max.ru/brandbook/max-colored.zip`.
- **Вид:** многоцветный градиентный знак-«диалог» (`#471AFF`, `#9500FF`,
  `#00BFFF`, `#6E1AFF`) — не перекрашивается.
- **Статус:** `CONFIRMED`
